# نستعلیق‌نویس
 
یادگیری خط نستعلیق با انیمیشن. متنی می‌نویسی و می‌بینی که با یک قلم متحرک از راست به چپ نوشته می‌شود؛ همراه با خط‌های هوا و زمین، ردیف لوزی‌های «نقطه» و پهنای هر حرف، درست مثل وقتی که استاد جلوی چشمت می‌نویسد.
 
سایت عمداً ساده است: یک navbar، یک input و یک بوم خروجی.
 
## ویژگی‌ها
 
- **نوشتن زنده:** هر متنی (تا ۴۰ نویسه) را به نستعلیق می‌نویسد؛ قلم متحرک کلمه را از راست به چپ آشکار می‌کند.
- **خط‌های اندازه‌گیری:** خط هوا، زمین (کرسی) و عمق، ردیف لوزی‌های «نقطه» به اندازهٔ پهنای کلمه، پشتهٔ پنج‌نقطه‌ای الف و پهنای هر حرف بر حسب نقطه.
- **خط‌کش هوشمند:** ارتفاع و پهنای واقعی کلمه اندازه‌گیری می‌شود و خط‌کش همیشه بالای بلندترین نقطهٔ کلمه می‌نشیند، نه داخل آن.
- **کپی به صورت تصویر:** نستعلیق نوشته‌شده را به صورت PNG در کلیپ‌بورد می‌گذارد (اگر مرورگر اجازه ندهد، تصویر دانلود می‌شود).
- **تم روشن و تاریک:** پیش‌فرض روشن است. تغییر تم با انیمیشن `circle-reveal` انجام می‌شود و انتخاب کاربر ذخیره می‌شود.
- **input با افکت فلزی:** با کتابخانهٔ `metal-fx`؛ اگر WebGL2 در دسترس نباشد، input عادی نمایش داده می‌شود.
- **موبایل:** در صفحه‌های کوچک، دکمه‌های navbar داخل یک منوی همبرگری با آیکن متحرک جمع می‌شوند.
- **آیکن‌های متحرک:** کپی، پاک‌کردن، اطلاعات، همبرگر و … همه با CSS خالص انیمیشن دارند.
- **کارت مودال:** پنجرهٔ مک‌مانند روی همهٔ عناصر، با پس‌زمینهٔ تار.
- **دسترس‌پذیری:** برچسب برای همهٔ دکمه‌ها، مدیریت فوکوس در مودال، و احترام به `prefers-reduced-motion`.
## استک
 
| بخش | ابزار |
| --- | --- |
| رابط | React 18 |
| ساخت و توسعه | Vite 5 |
| افکت فلزی input | `metal-fx` |

### از سایت (برای افراد عادی و روزمره)

برید به سایت [keyhan-tiny112.github.io/nastaliq-nevis واز نستعلیق نویس رایگان استفاده کنید هیچ ثبت نامی هم نیاز نیست](https://keyhan-tiny112.github.io/nastaliq-nevis)
 
Node.js نسخهٔ ۱۸ یا بالاتر لازم است (`.nvmrc`: نسخهٔ ۲۰).
 
```bash
npm install
npm run dev        # سرور توسعه، آدرس را خودش در مرورگر باز می‌کند
npm run build      # خروجی نهایی در dist/
npm run preview    # پیش‌نمایش خروجی build
```
 
با bun هم کار می‌کند:
 
```bash
bun install
bun run dev
```
 
پوشهٔ `dist/` فقط فایل استاتیک است و روی هر هاستی (Netlify، Vercel، GitHub Pages، Nginx و …) قابل انتشار است.
 
## ساختار پروژه
 
```
├── index.html                 نقطهٔ ورود، متاهای SEO و اسکریپت تم اولیه
├── vite.config.js             alias «@» → src، تنظیم سرور و تقسیم chunk ها
├── package.json
├── public/                    فایل‌های ثابت
│   ├── favicon.svg
│   ├── robots.txt
│   └── site.webmanifest
└── src/
    ├── main.jsx               راه‌اندازی React، فونت‌ها و استایل
    ├── App.jsx                حالت کلی برنامه و اتصال بخش‌ها
    ├── constants/             اندازه‌ها و ثابت‌های نستعلیق (نقطه، خط زمین، …)
    ├── components/
    │   ├── Navbar.jsx         نوار بالا و منوی همبرگری موبایل
    │   ├── TextField.jsx      input با افکت metal-fx و دکمهٔ پاک‌کردن
    │   ├── Card.jsx           پنجرهٔ مک به صورت مودال
    │   ├── IconButton.jsx · Toast.jsx · ErrorBoundary.jsx
    │   ├── icons/             آیکن‌های متحرک (Copy، Cancel، Info، Menu، …)
    │   └── stage/             بوم نستعلیق: خط‌ها، خط‌کش نقطه، الف، قلم (PenNib)
    ├── hooks/                 useTheme، useWriteProgress، useGlyphMetrics، …
    ├── lib/                   توابع خالص: خروجی تصویر، اندازهٔ جوهر، ارقام فارسی

```
 
نکتهٔ مهم: خود `metal-fx` از npm نصب می‌شود (`node_modules`). پوشهٔ `src/libs` فقط تنظیمات پیش‌فرض پروژه برای آن را نگه می‌دارد. آیکن‌های متحرک کامپوننت‌اند چون حرکتشان با CSS و حالت React کنترل می‌شود، برای همین در `src/components/icons` هستند و `public` فقط آیکن سایت را دارد.
 
## نحوهٔ کار
 
1. **اندازه‌گیری:** پس از بارگذاری فونت، پهنای کلمه و محدودهٔ هر حرف از خود SVG (`getBBox` و `getExtentOfChar`) خوانده می‌شود. ارتفاع و پهنای واقعی جوهر کلمه هم با `canvas.measureText` گرفته می‌شود (`src/lib/inkMetrics.js`).
2. **چیدمان:** ارتفاع بوم از خود کلمه می‌آید. خط زمین طوری پایین می‌رود که خط‌کش بالای بلندترین نقطهٔ کلمه جا شود.
3. **نوشتن:** `useWriteProgress` عددی از ۰ تا ۱ می‌سازد. با آن، یک `clipPath` کلمه را از راست به چپ آشکار می‌کند و `PenNib` همراه آن حرکت می‌کند. اول خط‌های راهنما کشیده می‌شوند، بعد نوشتن شروع می‌شود.
4. **واحد «نقطه»:** اندازهٔ همه‌چیز بر پایهٔ `NUQTA` (عرض قلم) حساب می‌شود. الف نستعلیق ۵ نقطه است.
## تنظیمات
 
ثابت‌های اصلی در `src/constants/nastaliq.js` هستند:
 
| ثابت | کار |
| --- | --- |
| `FONT_SIZE` | اندازهٔ فونت داخل بوم (و واحد `NUQTA` از آن می‌آید) |
| `MIN_BASELINE_Y` | کمترین فاصلهٔ خط زمین از بالای بوم |
| `RULER_HEADROOM` / `RULER_GAP` | جا و فاصلهٔ خط‌کش بالای کلمه |
| `DEFAULT_TEXT` | متن اولیه |
| `MAX_LENGTH` | بیشترین طول متن |
| `NARROW_BREAKPOINT` | مرز حالت موبایل (پیش‌فرض ۶۰۰ پیکسل) |
 
رنگ‌ها فقط دو متغیر هستند (`--bg` و `--fg`) در `src/styles/tokens.css`؛ بقیه از آن‌ها ساخته می‌شوند. برای تم جدید همین دو را عوض کن.
 
### استفاده از `Card`
 
```jsx
const [open, setOpen] = useState(false);
 
<IconButton label="درباره" onClick={() => setOpen(true)}>
  <InfoIcon />
</IconButton>
 
<Card open={open} onClose={() => setOpen(false)} title="درباره نستعلیق‌نویس">
  ...
</Card>
```
 
با دایرهٔ قرمز، کلیک روی پس‌زمینه یا `Escape` بسته می‌شود. شدت تاری پس‌زمینه با prop به نام `blur` (پیش‌فرض ۱۰ پیکسل) تنظیم می‌شود.
 
## محدودیت‌ها
 
- نوشتن به صورت آشکارشدن تدریجی با قلم متحرک است، نه ردگیریِ مسیر واقعیِ هر حرف.
- موقعیت خط‌های هوا و زمین تقریبی است و به فونت وابسته است.
- بازتاب فلزی `metal-fx` به WebGL2 نیاز دارد.
- کپی تصویر به کلیپ‌بورد در همهٔ مرورگرها یکسان پشتیبانی نمی‌شود؛ در این حالت تصویر دانلود می‌شود.
- تغییر تم با انیمیشن، به View Transitions API نیاز دارد. در مرورگرهایی که ندارند، تم بدون انیمیشن عوض می‌شود.
## سپاس و مجوزها
 
- [`metal-fx`](https://www.npmjs.com/package/metal-fx) (مجوز MIT)، ساخته‌شده بر پایهٔ Paper Shaders (Apache 2.0).
- فونت‌های Noto Nastaliq Urdu و Vazirmatn از طریق [Fontsource](https://fontsource.org) (مجوز OFL 1.1).
- حرکت آیکن‌های کپی و پاک‌کردن، بازسازی CSS از [hugeicons-animated](https://hugeicons-animated.com) است.
- انیمیشن تغییر تم از [Transition Kit](https://transition-kit.space) (`circle-reveal`) الهام گرفته است.
- مسیر آیکن GitHub از [Feather](https://feathericons.com) (مجوز MIT) است.
